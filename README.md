# مصاريفي — متتبّع المصاريف الذكي

مشروع Vanilla JS مبني بمبدأ **Separation of Concerns** بالكامل،
بدون أي مكتبات خارجية.

## 🏗️ المعمارية

| الطبقة            | الملفات                       | المسؤولية                        |
|-------------------|-------------------------------|----------------------------------|
| **Config**        | `config/constants.js`         | الفئات، الأشهر، مفاتيح التخزين   |
| **Utils**         | `utils/helpers.js`            | دوال نقية (تنسيق، تواريخ، IDs)   |
| **Services**      | `services/*.service.js`       | I/O: تخزين، CSV، رسم SVG          |
| **Core**          | `core/store.js`, `calculator.js` | نموذج البيانات + منطق الأعمال |
| **UI**            | `ui/ui.js`                    | تحويل البيانات إلى DOM            |
| **App**           | `app.js`                      | ربط الأحداث + تنسيق التحديث       |
